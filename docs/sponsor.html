支持 moon279 的开发工作

EmuHub-CN 是 EmuHub-APP 的中文适配版：界面汉化、国内加速下载、驱动与组件仓库持续整理维护。项目免费使用，如果它帮到了你，欢迎支持。

通过爱发电赞助

金额随意，按月或一次性都可以。国内支付宝 / 微信直接支付。

日常在做的事

  • 中文界面与专业术语翻译，去掉生硬的机翻
  • 组件与驱动下载走国内加速，避免 GitHub 限速
  • 驱动 / 组件 / 运行库仓库的整合、分类与推荐
  • 设备信息识别与驱动匹配，新驱动跟进测试

赞助花在哪里

服务器与 API 成本、测试设备、以及维护和排错的时间投入。每一笔都会直接回到项目本身。
