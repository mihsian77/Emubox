EmuHub-CN 是 EmuHub-APP 的中文适配版。做它的起因很简单：自己下载驱动太慢、界面全是英文，就想做个顺手的东西。没想到用的人越来越多，也就一路折腾到了现在。

技术上没什么了不起的：App 用 Kotlin + Jetpack Compose 从零重写，native 层用 C++ 做 Vulkan 设备信息采集和驱动加载；几十个驱动、组件仓库的自动分类、更新跟踪和国内加速下载，也都是自己一点一点搭的。能稳定跑起来、用户觉得好用，我就很满足了。

我是第一次认真维护开源项目，代码和界面都还有很多不成熟的地方，每次发版都提心吊胆，怕搞坏什么。感谢每一个下载、反馈问题、帮我校对翻译的人——是你们让这件事有了继续下去的意义。

如果你觉得它有用，欢迎请我喝杯咖啡。这不是交易，只是一份鼓励；它会变成服务器账单、测试设备，和下个版本里的新功能。
