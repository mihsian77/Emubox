它具体替你做什么

不生产驱动，也不打包模拟器。它做的是「找、配对、下载、管好」这四件最耗时间的事。

按手机型号配驱动

识别你的 GPU 是 Adreno 还是 Mali、属于哪一代，驱动按匹配度排序。不该装的会明确标出来，而不是让你一个个试。

组件与运行库一处找齐

Wine / Proton、Box64、DXVK、VKD3D、VC++ 运行库、.NET、字体……每条都写了用途和适用场景，不用猜。

下载走加速，断了能续

GitHub 直连慢的时候自动切到测速最优的加速节点。下载支持暂停、续传，下完的文件可以随时回看和整理。

一次典型的流程

以「我想在手机上玩某个 Windows 游戏」为例。

1
先看自己的机器能到什么程度

设备页读出芯片、GPU、内存和安卓版本，给出这台机器适合跑什么、瓶颈在哪。

2
挑一个模拟器装上去

模拟器库里按项目查看更新情况、维护状态和社区评价，直接跳到发布页下载。

3
换掉不合适的驱动

同一个 GPU 通常有几个驱动版本可选，App 会标出推荐项与已知问题，装错了也有记录可回退。

4
补齐缺的组件

游戏报缺 DLL、提示缺运行库，去组件与运行库专区按名字搜，说明里写了该放哪、要不要重启容器。

数据从哪来

条目不是手填的，也不在本地凭空生成。每条都能追到上游。

每天自动刷新，来源公开

仓库里的定时任务会去拉取上游发布信息、重建索引，然后由 App 按需下载。条数随上游变动，所以这里不写死数字。

常见问题

我的手机能装吗？

需要 Android 9.0 及以上，且是 64 位（arm64-v8a）设备。2019 年之后的中高端机基本都满足。

安装包只打 64 位架构，体积因此从 47MB 降到约 6MB。32 位机型（armeabi-v7a）没有对应版本，装上会提示「应用与设备不兼容」——这是机型限制，不是安装包损坏。

需要 root 吗？

不需要。EmuBox 是普通的安卓应用，装完就能用。驱动替换是在模拟器自己的容器里完成的，不碰系统分区。

它能让我手机上的游戏变快吗？

不能直接变快。它管的是「找对驱动、配对组件、把文件下下来」这一段，实际帧数取决于你的芯片、散热和模拟器本身。

换对驱动通常能解决花屏、闪退、启动失败；但指望换个驱动让帧数翻倍，不现实。

为什么有些条目显示「不适用」？

驱动和 GPU 架构是强绑定的：Turnip 只对 Adreno 有效，PanVK 只对 Mali 有效，三星 Xclipse 又是另一套。装错了轻则无效，重则进不去系统。所以它宁可不让你装。

下载很慢怎么办？

设置里可以切换加速模式：自动（测速后选最优节点）、手动（自己指定）、关闭（直连）。节点由社区维护，失效的会被自动清掉。

收费吗？会加广告吗？

免费，MIT 开源，没有广告和内购。维护成本靠自愿赞助，不影响任何功能。

和 Winlator、Eden、GameHub 是什么关系？

它们是模拟器本体，EmuBox 是给这些模拟器配套的下载管理器。你可以把它理解成一个「配件仓库 + 说明书」。

驱动、组件、模拟器的版权都归各自作者，EmuBox 只做索引、匹配和下载加速。
